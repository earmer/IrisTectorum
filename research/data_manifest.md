# Data manifest

Each source used in the research gets one entry: where it came from, its licence
(or "unknown"), when it was obtained, its hash, and what it is used for.

**Shipping policy:** the product ships **code and model weights only**. No
dictionary tables, corpora or lexicon files are distributed with it. Any
runtime table the code needs, such as character → pinyin, must come from a
source with a clear redistribution licence (e.g. Unihan).

**Licence review:** deferred to before release. Licences below marked
"unverified" were not checked against the source at the time of writing.
